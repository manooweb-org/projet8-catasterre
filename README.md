# CATASTERRE — Pilotage du projet d'évolution

CATASTERRE est une application web de visualisation des risques naturels par imagerie satellite, destinée aux notaires et aux agences immobilières. Ce dépôt sert au pilotage de son projet d'évolution : expérience utilisateur, disponibilité et architecture, fiabilité du développement.

## Backlog

Le Product Backlog et le Sprint Backlog sont tenus dans le projet GitHub public **[CATASTERRE — Backlog](https://github.com/orgs/manooweb-org/projects/2)**.

- **Epics** : issues parentes ; les user stories et tâches techniques en sont les sous-issues.
- **Champs** : Priorité (Haute, Moyenne, Basse, Luxueuse), Story points, Responsable, Status.

## Exports

Un projet GitHub ne conserve pas d'historique lisible : le backlog est exporté dans `exports/` à chaque jalon (v1 initiale, v2 après ajustement).
